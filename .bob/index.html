    How the counts work

    Each time Bob activates a skill, the hook in .bob/settings.json adds 1 to that skill in assets/data/skills-usage.json and refreshes assets/data/skills-data.js, which this page loads. The page checks for new counts every few seconds.

    To reset, set skills-usage.json to {} and run node .bob/assets/tools/skills.js build.
